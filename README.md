# skills-copilot-codespaces-vscode

Use this repository to learn how GitHub Copilot works and practice using it in VS Code.

## How Copilot works

GitHub Copilot uses AI to suggest code, explain code, and help you complete tasks faster.
It works best when you give clear prompts and enough context.

Core workflow:
- Describe your goal in plain language
- Let Copilot suggest code or steps
- Review and verify the output
- Iterate with follow-up prompts

## Practice Copilot in VS Code

Try these exercises:
1. Open a file and ask Copilot Chat to explain what the code does.
2. Ask Copilot to generate a small function, then refine it with a follow-up prompt.
3. Ask Copilot to write or improve a test for the function.
4. Request a refactor focused on readability and compare before/after behavior.
5. Ask Copilot to help debug an error and explain the root cause.

## Good prompt examples

- "Explain this file in simple terms and list the main responsibilities."
- "Create a function that validates email format and include edge cases."
- "Write unit tests for this function, including invalid input cases."
- "Refactor this block for readability without changing behavior."

## Validation mindset

Always review Copilot output:
- Run tests when available
- Check edge cases
- Confirm behavior matches your intent
